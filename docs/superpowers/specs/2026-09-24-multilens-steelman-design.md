# 多视角 Steelman 报告设计规格

## 目标

扩展 `person-deep-analysis`，使用户明确要求“多流派分析”或 Steelman 报告时，skill 能以可追溯证据为底座，公平呈现不同心理学理论镜头支持的候选解释、替代解释、冲突和未知信息。普通请求维持当前简洁、按材料量收敛的单人材料分析。

这是一套文本分析与假设组织方法，不是心理测验、临床评估、治疗、事实调查或风险预测工具；不宣称对人格、动机、创伤、关系结局或犯罪行为的准确性。

## 设计原则

1. **证据层先于理论层**：记录原话/具体行为、来源、情境、时间和上下文完整度。理论只能解释已经记录的材料，不能生成事实。
2. **视角按需启用**：仅在用户明确要求多视角/Steelman 深入报告时进入该模式。逐个说明视角是否适用；无足够材料时标为“不适用/信息不足”，不可为了覆盖理论而补写推断。
3. **解释并列、证据不等权**：每个仍有材料支持的解释都尽可能以其最强合理版本呈现；说明依据、额外假设、最强替代解释、反证和待核实信息。不制造虚假平衡，不将“客观中立”解释成所有解释等概率。
4. **冲突显式保留**：总结各视角一致的观察与不同的解释；不投票、不融合成单一人格类型、不输出伪精确置信度。
5. **临床工作与外部文本分析分开**：描述性整理不等于心理动力学治疗、CBT 治疗或人本主义咨询。不得诊断或指导治疗。
6. **犯罪/法证边界**：不把犯罪心理学作为一般人格侧写工具。只吸收来源核查、竞争假设、充分资料和行为情境等方法纪律；不预测犯罪倾向、欺骗、危险等级或罪责。明确威胁和现实危险继续由既有安全流程处理。
7. **主体性与隐私**：优先分析当事人明确表达的经验和偏好；第三方材料遵循最少引用和去标识化，说明宿主隐私处理不由 skill 控制。

## 视角资源

- `psychodynamic.md`：仅讨论本人报告或多个场景反复出现的情绪/关系主题；不推断潜意识、童年创伤或防御机制。
- `humanistic-and-needs.md`：呈现本人表达的价值、选择、意义、成长目标；以自主、胜任、联结作为开放提问。Maslow 只作历史启发，不采用固定需求层级。
- `developmental-psychology.md`：使用本人提供的年龄阶段、角色与环境变化作情境化理解，不倒推童年成因。
- `cbt-descriptive.md`：只整理本人明确报告的情境、想法、情绪和行为，不将第三方想法病理化或开展治疗。
- `forensic-evidence-boundaries.md`：提供资料来源和竞争假设纪律；明确禁止个人犯罪/危险性预测。
- `steelman-report.md`：多视角报告结构、适用性选择、假设比较与冲突综合。

资源通过入口按需读取，不把所有理论细节常驻主 `SKILL.md`。

## 报告结构

1. **问题与材料边界**：用户问题、材料来源、时序、视角完整度及上下文缺口。
2. **共同事实底座**：引用少量具体原话/行为，区分直接材料、转述和观察。
3. **视角适用性**：选择与问题匹配的镜头；对不适用镜头用一句话说明原因。
4. **候选解释**：每个解释列出视角、最强合理表述、材料依据、额外假设、合理替代解释、反证/未知。只纳入可由材料支撑的解释。
5. **对照综合**：共同观察、解释分歧、区分假设所需的新信息。不以多理论重复作为交叉验证。
6. **结论边界**：说明报告不代表诊断、人格定型、因果证据或未来风险预测。

用户只要简短回答时，不强制完整报告。出现即时自伤、暴力、胁迫或跟踪危险时，跳过理论镜头，进入既有安全优先流程。

## 仓库范围

- 重命名旧模块文件，消除标题中的过度推断暗示：M1 `deficiency` → `needs-and-preferences`；M3 `trauma-tracing` → `experience-and-development`；M5 `relationship-prediction` → `interaction-patterns`。同步所有引用和校验清单。
- 保留 M2 自我呈现、M4 优势与情境成本的描述性内容；审查其中是否含固定人格类型断言。
- 增加多视角回归场景并扩展行为报告；回归测试只验证行为边界，不代表心理理论有效性。
- 增加中文 blog 项目模块，以合成例子解释价值、流程、边界和验证状态；不宣称临床或预测能力。

## 验收标准

1. 主 skill 能区分普通模式和用户显式要求的多视角模式；入口路由所有详细视角资源。
2. 六份视角/报告资源都有具体适用问题、必要材料、可做推断、不能做推断和相关来源；所有外链为一手/专业来源，且不超出其来源支持范围。
3. 旧模块路径已完整迁移，所有文档、metadata、脚本与本地链接更新；无过期路径引用。
4. 新增至少 8 个多视角专项场景，覆盖适用性、Steelman 与虚假平衡、心理动力过推、发展因果倒推、需求层级误用、CBT 越界、犯罪预测、视角冲突和安全边界；场景校验可验证 ID 和类别。
5. blog 项目模块可独立复制发布，含一段明确标注为合成的多视角演示，并披露尚未完成的宿主和用户效果验证。
6. 仓库验证器、eval 校验器、skill-creator quick validator、YAML 解析、Skills CLI 发现与隔离安装检查通过；新增场景经人工按规则走查，验证范围如实记录。

## 明确不在范围内

- 将心理学理论组合宣称为经过验证的统一模型。
- 从文字推断潜意识、精神障碍、创伤史、危险性或犯罪倾向。
- 提供临床治疗、法证意见、司法结论或个体风险分数。
- 使用真实私人材料作为测试、示例或 blog 素材。
- 创建远端仓库、对外发布或联系社区。
