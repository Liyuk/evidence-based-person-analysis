# 合成演示与分享素材

所有人物、引语和场景均为虚构。发布时保留“合成示例”标记，不补充能让人误以为是真实个案的细节。

## 方向一：从一句话拆出观察与未知

> **合成示例**：“我喜欢独处，但希望伴侣每天联系；忙的时候我会晚些回复。”
>
> 观察是三项并存的偏好/情境：喜欢独处、希望日常联系、忙时会延迟回复。可以提出“个人空间和稳定联系都重要”作为候选解释；但“每天联系”具体意味着什么、忙时如何沟通，仍然未知。仅凭这句话不能判断依恋类型。

## 方向二：一次延迟回复能说明什么

> **合成示例**：某人八小时未回复。
>
> 能观察到的只有回复间隔。工作、睡眠、手机不可用、个人习惯都可能解释它。除非有更多可比较情境和双方约定，否则不能从这一次延迟推断人格或关系意愿。

这个 Skill 会把分析范围收在材料能支持的地方；它不会替你猜心或决定关系去留。仓库：<替换为公开仓库链接>。

## 方向三：单段争执，不拼出长期循环

> **合成示例**：A 给出工作建议，B 回答“我现在只想先被听见”。
>
> 这段材料支持描述一次“建议—表达倾听需求”的往返。它还不足以证明谁长期控制、谁回避，也不能确认任何人的创伤经历。需要多段可比较互动，才有条件讨论重复模式。

## 方向四：同一材料，多种解释，不强行合并

> **合成示例**：“我担心被批评，所以伴侣问我怎么了时，我常说没事去独处；我也确实很重视个人空间。”
>
> CBT 描述镜头可以按本人自述整理“被询问 → 担心批评 → 独处”；人本/需求镜头指出自主空间是本人明确说出的偏好。心理动力学镜头可能会提出是否存在重复主题的问题，但不能由此断言童年原因。几个角度共享部分材料，却不是多次验证同一个因果结论。

这个 Skill 的多视角模式会说明哪些解释依赖额外假设，哪些信息仍不足；它不会为了“全面”而给每个学派编出一个答案。仓库：<替换为公开仓库链接>。

## 发布约束

- 不贴用户或第三方的真实私聊、截图、照片、账号名、位置、病史或能拼接识别身份的片段。
- 不暗示 Skill 能读心、诊断、识别“渣/坏人”、预测关系成败。
- 不把启发式或单个演示写成科学验证结果；分享时链接到限制说明。
- 分享前将占位链接替换为已公开的仓库 URL，并验证安装命令。
