# 不替你猜心：一个把心理学视角与文本证据分开的 Agent Skill

> 可作为项目介绍文章的主体直接发布。发布前请替换安装仓库地址，并确认实际支持的宿主；文中的示例为合成文本。

很多人拿着一段自我介绍、一条消息或一次争执来问模型：“这说明对方是什么样的人？”模型很容易把一个信号扩写成稳定人格、隐藏动机、童年创伤，甚至关系结局。问题在于，材料只是一小段，而结论常常写得像已经看透一个人。

**人际深度解析（Person Deep Analysis）** 是一个 Agent Skill，目标不是替人读心，而是把材料拆成可以核对的观察、有限的解释、替代可能和未知信息。普通请求保持简洁；只有用户明确要求时，才展开多心理学视角的 Steelman 对照。

## 它如何工作

分析先从材料本身开始：这是谁说的？是原话、转述还是剪辑片段？发生在什么情境？然后才考虑解释。证据不足时收窄范围；第三方私密材料应尽量去标识，只提供与问题有关的最少片段。

在多视角模式中，心理动力学、人本主义与需求模型、发展心理学、认知行为视角各自提出不同的问题。它们不是给同一个人盖上更多标签，而是帮助读者比较：哪些解释能被材料支持、它们额外依赖哪些假设、什么信息可能推翻它们。视角不适用时会明确省略。解释有冲突时保留冲突，不把“多个理论都说了”当作互相验证。

### 合成示例：同一段话，不等于一个人格结论

> “我从小家里很少谈感受。伴侣问我怎么了时，我怕被批评，就说没事、一个人待着；我也很看重自己的空间。”

**共同观察：** 说话者报告了家庭沟通背景、对被批评的担心、在伴侣询问时选择独处，以及对个人空间的重视。这些内容来自本人叙述；我们没有伴侣的视角，也不知道类似互动发生的频率。

- **认知行为视角：** 本人已描述“伴侣询问 → 担心被批评 → 说没事并独处”的关联。害怕之外的情绪、伴侣实际如何回应、独处后是否继续沟通，仍未知。这是对自述的整理，不是诊断或治疗。
- **人本主义/需求视角：** 个人空间是说话者明确表达的偏好；亲密连接和自主空间可以同时重要。还需由本人说明两者如何平衡，不能替其宣布“真正需要什么”。
- **心理动力学视角：** 多次相似互动可能值得探索关系期待是否重复；当前例子只能提出问题，不能证明家庭背景造成了现在的反应，也不能推断潜意识或创伤。
- **发展心理学视角：** 家庭沟通方式是本人提供的背景。材料没有时间线或其他成长信息，无法据此建立发展因果。
- **法证/犯罪心理：** 当前材料没有需要该领域处理的法律或犯罪问题，因此不适用；它也不能用来给这段关系做危险性或犯罪预测。

**Steelman 对照：** 一种有依据的理解是，说话者用独处保护自己的空间，并暂时减少被批评的担忧。至于独处是否影响双方理解或后续修复，当前没有伴侣视角和后续互动证据，只能作为待检验的互动影响问题，不能当成已有材料支持的竞争解释。需要知道双方后来是否谈回这件事、伴侣具体如何回应，以及这个过程是否在多个场景中重复。

## 它和关系顾问有什么不同

与面向行动建议的关系工具相比，本项目默认回答的是“这段材料能说明什么、还不能说明什么”，而不是“我该怎么做”。用户明确需要行动建议时，应把建议与证据分析分开；项目不替用户决定是否继续一段关系。

## 理论使用边界

这些心理学视角的临床或学术研究，不自动证明它们能从简短文字可靠推断个体心理。Maslow 需求层次在这里不是固定阶梯；CBT 模式仅整理本人明确报告的体验；发展与心理动力解释不倒推童年因果。法证/犯罪心理不用于罪犯侧写、犯罪倾向判断或危险等级评分。遇到现实中的自伤、暴力、胁迫或跟踪线索，先处理安全，不继续普通画像。

项目使用 MIT 许可证，欢迎提交合成案例、边界修正和宿主兼容反馈。当前仓库结构、安装说明和行为回归场景有自动校验；这些检查证明的是文件与规则覆盖，不是心理学效度、模型准确率或真实宿主中永远遵守边界。普通提示与 skill 输出的对照评估仍需实际执行，当前也没有盲评或用户效果结论。

**项目价值的主张很克制：** 让模型分析人物材料时，把证据、理论解释、替代可能和判断边界展示出来，供人检查与修正。
