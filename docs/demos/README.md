# 场景演示：从事件拆解到判断更新

这组演示呈现互动风险分析在不同现实问题中的使用效果。结构按用户面对的问题平衡安排，避免把项目误读成只用于反诈。所有情境均为合成材料，不是真实受害者故事，也不是准确率测试。**这些 A/B 输出是在更名前用旧 Skill ID `$person-analysis` 生成的历史结果；正文保留原运行名称和输出，不代表新 ID 已对这 8 例重跑。**

## 四类场景，各两例

| 用户面对的问题 | 案例 | 关注点 |
|---|---|---|
| 网恋与金钱风险 | [网恋投资邀约](01-romance-investment.md)、[兼职先垫资](02-task-deposit.md) | 识别关系建立、催款、收益说法和付款风险；先暂停不可逆操作，再核验 |
| 情绪操控与情感虐待 | [家庭关系中的借钱压力](03-emotional-blackmail.md)、[亲密关系控制与威胁](04-emotional-abuse-and-control.md) | 拆解内疚施压、冷处理、隔离、监控与威胁；把安全和边界选择还给当事人 |
| 人际关系霸凌 | [同辈排斥与网络羞辱](05-peer-bullying.md)、[职场羞辱与责任归属](06-workplace-bullying.md) | 记录重复性、权力差、实际影响与替代解释，不擅自作正式定性 |
| 误判控制与证据更新 | [单次记忆冲突](07-single-memory-conflict.md)、[新反证降低排斥疑虑](08-counterevidence-update.md) | 防止把单次冲突升级成操控标签；出现反证后相应调整判断 |

## 对照设置与解读

- 每例同一段提示分别运行在空白临时 Codex 项目和安装 `person-analysis` 并显式调用 `$person-analysis` 的新会话中。共 8 例、16 次运行，Codex CLI `0.156.1`、`gpt-6-luna`、只读沙盒；所有调用成功。
- 每篇收录普通 Codex 和显式 Skill 的完整输出。对照点包括事件拆解、证据与未知、替代解释、反证更新、安全选择和主体性。
- 观察来自维护者逐例定性比较，不是独立盲评。基线模型本身多次已能提供完整而安全的回答，Skill 并非每例都带来明显增量。

## 这组例子显示了什么

Skill 的核心是把“发生了什么、重复到什么程度、行为实际造成什么效果、可能的立场或目的有哪些、还缺什么信息、哪些行动由用户决定”组织成可检查的分析过程。模型本身可以从训练中识别不少模式；Skill 不垄断这种能力，也不能把先验联想关掉。它提供的是一套提示纪律，要求把线索、因果假设、意图推断和未知分开，方便使用者质疑和修正。网恋诈骗只是其中一类；同样重要的应用是辨别情绪施压和霸凌，以及避免误把单次失误、关系冲突或普通疏漏叫作煤气灯/霸凌。

这组样例支持的是工作流程价值，不是心理诊断、犯罪预测或现实准确率承诺。公开资料用于构造合成情境，不代表官方机构认可本 Skill；地域来源及局限见[一手来源研究](../research/demo-scenario-sources.md)。
