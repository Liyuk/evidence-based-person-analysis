# 场景演示：从事件拆解到判断更新

这组材料按用户面对的问题整理八个合成场景，供阅读事件拆解、风险核验、替代解释和判断更新等分析主题。场景并非真实受害者个案。

## 四类场景，各两例

| 用户面对的问题 | 案例 | 关注点 |
|---|---|---|
| 网恋与金钱风险 | [网恋投资邀约](01-romance-investment.md)、[兼职先垫资](02-task-deposit.md) | 识别关系建立、催款、收益说法和付款风险；先暂停不可逆操作，再核验 |
| 情绪操控与情感虐待 | [家庭关系中的借钱压力](03-emotional-blackmail.md)、[亲密关系控制与威胁](04-emotional-abuse-and-control.md) | 拆解内疚施压、冷处理、隔离、监控与威胁；把安全和边界选择还给当事人 |
| 人际关系霸凌 | [同辈排斥与网络羞辱](05-peer-bullying.md)、[职场羞辱与责任归属](06-workplace-bullying.md) | 记录重复性、权力差、实际影响与替代解释，不擅自作正式定性 |
| 误判控制与证据更新 | [单次记忆冲突](07-single-memory-conflict.md)、[新反证降低排斥疑虑](08-counterevidence-update.md) | 防止把单次冲突升级成操控标签；出现反证后相应调整判断 |

## 阅读限制

这些案例是合成材料，用于观察分析方法，不构成独立盲评、效果证明或准确率数据。公开资料只用于构造合成情境，不代表来源机构认可这些分析；来源及地域局限见[场景来源说明](../research/demo-scenario-sources.md)。
