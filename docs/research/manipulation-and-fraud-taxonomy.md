# 情绪操控、霸凌与电诈：公益型识别框架调研

## 结论先行

目前没有一个权威、穷尽的“负面心理手段总数”。心理学、反家暴、职场安全和执法机构的分类目的不同；常见手段也彼此重叠，会随着媒介和社会情境变化。为 skill 设计实用索引，可以先整理为 **10 个场景/手段大类**，但这只是导航框架，不是封闭清单、诊断表或识人测验。

中国公安部刑侦局、国家反诈中心发布的《2025版防范电信网络诈骗宣传手册》列出 **10 类高发电诈场景**。这个数字是该手册按场景归类的范围，不代表电诈只有十种，也不是全部操控方式的统计。[司法部智慧普法平台转发的手册发布信息](https://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202506/t20250619_521225.html)

## 10 个实用分类

下表中的行为是核对线索，不是单项确证。一次严重威胁或一次被骗转账也可能需要立即支持；相反，一次争执、表达不满或记忆分歧，单独不足以证明霸凌、煤气灯或胁迫控制。

| 大类 | 常见行为线索 | 分析时要核对什么 |
|---|---|---|
| **1. 情绪/心理伤害** | 反复羞辱、贬低、恐吓、监控、孤立、以冷落/撤回关爱作惩罚、利用性或经济压力 | 行为是否反复；当事人能否拒绝、表达异议、维持社交联系及自主安排生活。美国全国家庭暴力热线将用来控制、孤立或恐吓伴侣的非身体行为列为情绪虐待表现之一。[来源](https://www.thehotline.org/resources/what-is-emotional-abuse/) |
| **2. 情绪勒索/愧疚施压** | 以抛弃、报复、自伤、曝光隐私或撤回支持相威胁；反复诉诸恐惧、义务或内疚来迫使对方答应 | “不”是否仍是可选项；是否把另一成年人所有决定或安全都压给用户。自伤表达可能是真实危机，不能先验地说成操纵；须把即时安全和是否存在强迫模式分开评估。 |
| **3. 亲密关系中的胁迫控制** | 切断支持网络、限制行动/通信/金钱/工作/医疗选择、监视、威胁或性胁迫 | 看多种行为如何组合、是否持续收窄当事人的自由与安全；不要把一次意见不合当作控制模式。WHO 将心理伤害和控制行为纳入亲密伴侣暴力的描述范围。[来源](https://www.who.int/health-topics/violence-against-women/) |
| **4. 煤气灯/现实感削弱** | 持续否认、扭曲事件或贬损当事人的记忆和判断，特别是与责怪、控制、孤立并存时 | 分开记录可核实事件、各方说法与未知；不能由一段聊天判断内心意图。普通记忆错误、一次说法不一致或不同意见本身不构成模式。热线资料把持续否认事件作为可能的情绪伤害行为之一。[来源](https://www.thehotline.org/resources/what-is-emotional-abuse/) |
| **5. 职场霸凌/权力滥用** | 公开羞辱、恶意造谣、排斥、故意破坏工作、抢功甩锅、不合理施压、削弱他人完成工作的条件 | 核对具体行为、日期、目击者、工作影响、权力差和报复风险。Acas 将滥用权力、羞辱、伤害列为职场霸凌相关表现；适当且私下的绩效反馈不自动等于霸凌。[Acas](https://www.acas.org.uk/bullying-at-work)。ILO《暴力与骚扰公约》覆盖一个或反复发生、可能造成身心、性或经济伤害的不可接受行为或威胁。[ILO C190](https://www.ilo.org/resource/other/c190-violence-and-harassment-convention-2019-no-190) |
| **6. 同伴/群体/网络霸凌** | 反复嘲弄、威吓、排斥、散布恶意传言、群体围攻、用社交地位孤立个人 | 核对发生场景、是否重复、群体权力结构、现实安全和支持网络；不要默认建议当事人独自对质。也要区分一般冲突与持续针对。 |
| **7. 冒充身份/权威型诈骗** | 冒充政府、警方、银行、平台客服、雇主、亲友或技术人员；制造案件/账户恐慌、假费用、紧迫付款或索取验证码 | 通过自己找到的官方渠道独立核验；不要使用可疑消息提供的电话、链接或账户。中国 2025 手册列有冒充领导熟人、冒充公检法、冒充电商物流客服、贷款征信等类型。[官方发布信息](https://legalinfo.moj.gov.cn/zhfxfzzx/fzzxyw/202506/t20250619_521225.html) |
| **8. 婚恋/熟人信任型诈骗** | 虚构身份或处境、快速建立信任、转去非平台沟通、编造医疗/旅行紧急情况、要求保密或借“带你赚钱”推投资 | 核验身份与事实，特别留意关系建立后出现的转账、投资、验证码或保密要求；避免羞辱受害者。FTC 描述了先建立信任、再编造理由索款及要求难追回支付方式的常见套路。[FTC](https://consumer.ftc.gov/articles/what-know-about-romance-scams)。FBI 说明加密投资诈骗也可能以婚恋或信任关系为入口。[FBI](https://www.fbi.gov/how-we-can-help-you/victim-services/national-crimes-and-victim-resources/cryptocurrency-investment-fraud) |
| **9. 投资/传销/兼职与收益机会骗局** | 保证高收益或“低风险”、假平台/假盈利截图、限时催促、以发展下线为主要收益来源、反复购买库存/培训、缴费才能提现或获佣 | 区分高风险但合法的经营与虚假陈述、非法集资或传销；核查收益来源、费用、合同和监管信息。FTC 提醒并非所有多层次营销都自动违法，但若收益主要依靠招募而非真实零售，可能涉及金字塔骗局。[FTC](https://consumer.ftc.gov/articles/multi-level-marketing-businesses-and-pyramid-schemes)。法律性质依所在地法规判断。 |
| **10. 电信/网络渠道型诈骗** | 电话/短信/邮件/社交平台钓鱼，号码伪造，企业邮件诈骗，假技术支持与远程控制，盗号，勒索/裸聊敲诈，假工作/刷单任务，虚假游戏交易 | 识别对方要求的是转账、验证码、口令、远程访问还是私密影像；从独立可信渠道联系银行/平台/运营商。渠道型手段常与冒充、婚恋或投资骗局组合，不应当成彼此排斥的类别。 |

中国 2025 年手册列出的 10 类高发电诈**场景**是：刷单返利、虚假网络投资理财、虚假购物服务、冒充电商物流客服、贷款征信、冒充领导熟人、冒充公检法、婚恋交友、网络游戏产品虚假交易、机票退改签。最高检披露的办案情况也提到，诈骗套路常被拼接组合，例如先以情感交友建立信任，再引导至虚假投资平台；因此按“单一骗局类型”看，容易漏掉复合型诈骗。[最高检相关工作情况](https://www.spp.gov.cn/spp/xwfbh/wsfbt/202311/t20231130_635181.shtml)

## 跨类别风险线索

下列信号只用于决定“要核查什么”，不单独证明恶意：

- 用户一想暂停、核实、寻求第二意见，对方就加码催促、威胁、羞辱或惩罚；
- 要求保密、切断亲友/同事支持，或不让联系官方机构；
- 关系、工作或资金选择逐渐变少，拒绝会带来惩罚；
- 可核实说法反复改变，付款账户、身份、收益来源或权限要求无法独立验证；
- 从小额试探或短暂亲密迅速升级到高额转账、远程控制、性/隐私材料或更强依赖；
- 对方否认具体行为、攻击提出问题的人、反转责任，或者短暂道歉后重复相同模式。

需要保留反证与替代解释。与此同时，不确定对方动机或法律归类，并不要求把已经发生的伤害说轻。

## 对公益型 skill 的建议

1. **不责怪求助者**：易受骗或受控不等于不聪明。信任、孤独、急迫、经济压力、信息差和权力差都可能被利用；任何人都可能在特定处境里遇到风险。
2. **先回应人的当下需要**：先问最想处理的是安全、钱款/账号、工作影响、关系边界，还是核实一件事；提供少量选项，不命令人立刻对质、离开、报警或举报。
3. **对行为明确，对动机谨慎**：可说“这几次发生了什么、造成什么影响”，慎用“操纵者、NPD、精神病态、煤气灯”等定性标签；术语不等于诊断、证据或法律结论。
4. **对抗不等于报复**：协助暂停付款/共享信息、独立核验、寻求可信支持、了解组织渠道或本地官方服务；不教反向操控、诱捕、公开羞辱、威胁、跟踪或规避问责。
5. **评估对质和留存信息的风险**：权力不对等、设备监控或可能报复时，不默认建议正面交锋、秘密录音、突然更改设备或公开曝光。是否记录、向谁披露由当事人依安全和当地法律选择。
6. **实时信息须本地核实**：法律、工作申诉程序、反诈热线和资金追回渠道会因地区而异且可能变化。给具体流程前查所在地的官方来源；紧急危险优先联系当地紧急服务或可信的即时支持。

## 术语和边界

“情绪勒索”“PUA”“煤气灯”“love bombing”“DARVO”等词在大众语境和研究语境中的定义并不完全一致，有的不是正式临床术语。DARVO 有关于旁观者判断与受害者自责的实证研究，但不因此成为判断某个具体人的自动分类器。[Harsey & Freyd (2023)](https://journals.sagepub.com/doi/abs/10.1177/08862605231169751)。即使某行为看起来像一种常见手段，也要回到原话/动作、频率、情境、边界、影响和可核实信息。

本分类是首轮工作地图，来源偏向国际机构、美国反诈资料与英国职场指南，不是任何司法辖区的法律意见，也不是临床评估或经过验证的风险量表。官方反诈列表用于实务宣传和案件分类，不等于流行率排名或所有骗术清单。文本可能缺少语气、时间线、线下事件、权力关系和相反证据；该地图用于组织支持问题，不用于宣告人格、动机或犯罪事实。
