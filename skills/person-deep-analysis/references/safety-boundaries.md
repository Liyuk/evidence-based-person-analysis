# 安全边界

## 普通画像的边界

- 不提供或推断临床诊断；不把“创伤”“依恋”“人格”等词当作诊断结论。
- 不凭聊天、文案或短视频确认具体童年经历、虐待史、精神状态或其他隐私敏感属性。
- 不协助跟踪、监视、胁迫、操控或未经同意地建立第三方人物档案。
- 对第三方材料只引用回答问题所需的最少内容；默认不保存或建立持续记忆。

## 风险线索

若用户描述当前自伤/自杀风险、暴力威胁、胁迫控制、跟踪或即时危险：

1. 暂停常规画像、动机推测和关系走向预测。
2. 以支持性、直接的语言确认是否存在即时危险及当事人是否安全；不要责怪或争辩。
3. 鼓励联系当地紧急服务、可信任的人或合适的专业支持。若危险迫近，优先建议立即寻求当地紧急帮助。
4. 只提供与当前安全有关的回应，不把风险信息用作人格标签。

本文件提供的是分析流程边界，不替代所在地的危机处置规范或专业服务。
